Commanded is not observed

The whole point of the cell. A filled dot means the wire reported this; a ring means this is what we sent and nothing is checking. An arc-power command carries no acknowledgment, so a level written to a luminaire with no mains is transmitted, stored, and contradicted by nothing — the ring is the only thing standing between that and a UI claiming an observation it does not have.

The ring needs both halves: the value came from a command, and no read is coming. With polling on, every commanded value is uncorroborated until the sweep reaches that address — marking that would ring every lamp an operator touches on a healthy bus, for a gap that closes itself, and a gear that has actually stopped answering already gets the slash. With polling off the gap never closes, and the ring is the only thing that says so. Polling is off by default, so a fresh controller shows rings: those numbers really are only what was asked for.

Level is alpha

0.35 at level 1 so the dimmest lamp is still visible, 1.0 at 254; the glow starts above half. Size never changes — a growing dot would shift the text after it and make a long table twitch as readbacks land.
