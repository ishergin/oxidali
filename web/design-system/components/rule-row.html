The runtime line is the rule's own record since the controller booted: how many times it fired, the latency of the last firing and when it fired. A time with a leading + is time since boot — the clock was not anchored when the rule fired. A rule that never fired says so in words rather than in zeros, and carries no outcome.

partial is a distinct outcome, not a failure: a three-lamp scene that failed on the second lamp left the third correct, which is closer to the operator's intent than an abort. refused means the engine did not run the rule at all; the reason follows the time. A disabled rule keeps its last record. The toggle answers instantly (a manifest bit), never through the chunked document write.
