Operation lifecycle

unknown is neutral on purpose, and it is not the same as a failure. The controller keeps a finished operation for sixty seconds; a client that asks after that gets a 404 and genuinely cannot learn how it ended. Painting that green claimed a write had landed — the screens act on that answer, clearing an operator's edited rows — and painting it red would accuse a write that most likely succeeded. Neutral says the one true thing: nobody knows any more.
