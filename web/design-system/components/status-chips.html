Presence

Present not probed not answering

A lamp's power and level are not a chip. A chip has a fixed hue for a named condition; a lamp's state carries its own colour and level, so it has its own cell (components/lamp-state), and a gear that stops answering shows there as no answer. The input-device header uses all three chips; the physical-device header shows only Present.

Attribute source / freshness

readback · 12 s ago written · 3 m ago never read

Not a chip: the last column of an attribute row on the device page. readback is a value the gear answered to a read, written one the controller wrote and the gear confirmed. Input-device values say read, or stored for a value the controller holds with no read time:

read · 40 s ago stored never read

Operation lifecycle

accepted running succeeded failed interrupted timed out cancelled unknown

interrupted is a failed operation whose error is preempted: it stood down for an operator command. It carries no failure detail, and its toast reads Stood down for an operator command, with retrying when the action starts it again.

unknown is neutral on purpose, and it is not the same as a failure. The controller keeps a finished operation for sixty seconds; a client that asks after that gets a 404 and genuinely cannot learn how it ended. Green would claim a write had landed — the screens act on that answer, clearing an operator's edited rows — and red would accuse a write that most likely succeeded. Neutral says the one true thing: nobody knows any more.
