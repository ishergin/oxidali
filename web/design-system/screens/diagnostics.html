2026-09-12 — three cells that say what a wait costs

A FreeRTOS tick on this board is 10 ms, and ESP-IDF runs any shorter sleep as esp_rom_delay_us — a busy-wait that parks nothing, so the idle task on that core never runs and the only symptom is a task watchdog naming a thread that is not at fault (ISSUE-74). Three cells make the cost readable: PHY sniffer · Poll fast and DALI wire · Session spins count passes whose back-off was too short to park, so each is literally a millisecond of burned CPU, and Redundancy · Arbitration table is the mode that decides the sniffer's pacing.

Neither counter is a fault, and neither is painted as one: read them against the page header's uptime — poll_fast / uptime_ms is the fraction of a core the sniffer holds. The Redundancy card is also new here; the screen has rendered it since R17 and this card had not caught up.

2026-09-01 — the seventeenth block

/api/v1/diagnostics publishes seventeen blocks and this page rendered sixteen. The missing one was rules, and it is not a harmless omission: hydrate_failed means a rule set that failed to load, which is a rule set that silently does nothing — an operator's automations simply absent, with no symptom on any other surface. It joins persist_failed and effects_ingress_rejected in FAULT_KEYS.

Found by counting the DTO's blocks against the screen's, and kept counted by scripts/verify_read_surface.py. uptime_ms and mqtt are the two documented exceptions here — the first is in the page header, the second has its own card because its connected is a boolean.
