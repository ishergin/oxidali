2026-09-01 — delete, colour, and one column fewer

Delete is new, and it is not Unbind: unbinding drops the binding and keeps the configuration so a lamp can move to a replacement luminaire, while deleting removes the record — name, Home Assistant entity, binding, desired group row, rows in all sixteen scenes. Until it existed there was no way back from a lamp created by mistake, and the only remedy in the field was resetting the whole persisted slice. It arms before it fires, the same two-step Unbind has always used, and one row can have only ONE armed action: two red Sure? buttons a few pixels apart is how an operator deletes a lamp they meant to unbind. It sends nothing to the bus — the membership already programmed into the luminaire stays as it is.

Type · declared is gone (the bound device's card is where a type belongs, with its override control beside it), and State carries the fixture's colour — components/lamp-state.
