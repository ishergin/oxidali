Policies

Settings

What a luminaire does when the bus falls silent or mains returns. These are the gear’s own NVM variables, not settings of ours.

Fallback levels

System failure level
Where the gear goes when the bus has been silent for more than 500 ms (102 §9.12). Empty = unmanaged: this controller writes it on no device. 0–254.
Power-on level
Where the gear goes when mains returns. Empty = unmanaged. 0–254.
Write to a device as it is discovered
Otherwise the policy reaches a device only when you apply it below.

Write it to the installation

Every known device
One write per device, paced. A device that confirms nothing costs one timeout and is reported — silence from a gear the registry believes is present is a fault worth seeing.

Nothing is managed, so there is nothing to write. IEC 62386-102 defaults both variables to 0xFE — full brightness — so an installation that has never been asked goes to 100 % when the bus dies or the power returns.
