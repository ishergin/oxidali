# Стабильность и версионирование API

Правила эволюции контракта, семантика `PATCH` и три дисциплины ответа, из которых
выбирает каждый маршрут.

**Границы:** формы ошибок — [`contracts/error-dto.md`](contracts/error-dto.md);
общие формы состояния — [`contracts/state-contracts.md`](contracts/state-contracts.md);
чек-лист изменения контракта —
[`../contract-stability-checklist.md`](../contract-stability-checklist.md).

## Правила стабильности

- Задокументированное публичное поле стабильно; добавлять поля можно.
- Удаление поля, смена написания enum'а или типа поля — только через `/api/v2` или
  явную миграцию.
- Неизвестное поле запроса — ошибка; неизвестное поле ответа клиент обязан терпеть.
- `null` допустим только у полей, которые документированы как nullable, и значит
  «не известно / не прочитано», а не ноль.
- Runtime-значения (наблюдённые с провода) и сохранённая конфигурация — разные
  факты и не смешиваются в одном поле.

## Написание enum'ов

В Rust (`dali2rust-contracts::msg`) значение пишется PascalCase, в JSON (REST, WS,
MQTT) — snake_case. Единственное место, где задаётся JSON-имя, — методы `rest_name()` /
`as_str()` самих enum'ов; REST и WebSocket берут имя оттуда и потому не могут
разойтись. Какие enum'ы являются контрактом — [`contracts/enums.md`](contracts/enums.md).

## Семантика `PATCH`

`Content-Type: application/merge-patch+json`, строгий RFC 7396:

- отсутствующее поле не меняется; значение заменяет; `null` очищает nullable-поле;
- массив заменяется **целиком** — частичного слияния массивов нет;
- нарушения отвечаются общими кодами HTTP ([`contracts/error-dto.md`](contracts/error-dto.md)):
  неизвестное поле, read-only поле, значение вне enum'а или диапазона, режим вне
  effective capabilities, пустой `PATCH`.

### Матрицы групп и сцен

- `rows` в теле — только затронутые строки; строки, которых нет в теле, не меняются.
  Отдельных маршрутов на строку или ячейку нет.
- `PUT` матрицы — полная замена: ровно 64 строки, без дублей `virtual_lamp_id`.
- Правка матрицы меняет только `desired`; на провод идёт лишь явный `apply`.
- Форма строки — у ресурса: [`resources/groups.md`](resources/groups.md),
  [`resources/scenes.md`](resources/scenes.md).

## Дисциплины ответа

Маршрут не выбирает «как удобнее», а относится ровно к одной из трёх дисциплин: все
handler'ы исполняются на одной задаче httpd
([02](../../architecture/02-runtime-and-threading.md) §The HTTP task).

| Дисциплина | Ответ | Где |
|---|---|---|
| **Синхронное подтверждение** | Handler публикует команду(ы) и ждёт подтверждения шины под **одним общим дедлайном** `confirmation_timeout_ms` (2000 мс), даже если команд несколько. Успех — `200` с ресурсом или `{correlation_id, status}`. | target-state (VL, PD, группа), вызов сцены, expert-шаги commissioning, `POST /redundancy/switchover`, диагностика `/dali/*` |
| **Запись с read-after-write** | Публикация → подтверждение → ожидание счётчика применений (или ревизии) владельца данных → `200` с обновлённым DTO (или `204` для удалений). Следующий `GET` гарантированно видит запись. | `PATCH` метаданных и настроек, привязка ламп, удаления записей, `PATCH /rules/{name}`, импорт слайса конфигурации |
| **`202` + `operation_id`** | Handler ничего не ждёт. Тело — `{operation_id, type, status: "accepted"}`; исход читается через `GET /operations/{id}` или канал WS `operations`. | discovery, чтение/запись атрибутов, apply групп и сцен, чанковые записи конфигурации (`config_write`), commissioning, HA discovery, политики, обновление прошивки |

Коды отказов обеих синхронных дисциплин — [`contracts/error-dto.md`](contracts/error-dto.md).

- **`202` — не «записано».** Операция может завершиться `failed` уже после ответа
  (например, отказ коммита чанковой серии оставляет на устройстве прежнюю
  конфигурацию). Клиент, который применяет результат, обязан дождаться терминального
  `succeeded` ([`resources/operations.md`](resources/operations.md)).
- **Чанковая запись конфигурации атомарна.** Матрица групп или сцены, расписание HCL и
  документ правил не помещаются в кадр шины и уходят серией, которую реестр применяет
  целиком или никак ([`../bus-contracts/commands.md`](../bus-contracts/commands.md)
  §Чанковые записи); кадров на провод такая запись не шлёт.
- Маршрут с иной дисциплиной обязан принести собственного слушателя отказов шины
  ([03](../../architecture/03-bus-and-backpressure.md) §A refusal needs a listener).
