# Ресурс: Settings — Display

Настройки встроенного OLED: включение, адрес I2C, поворот, хранитель экрана и какие
страницы листать.

**Границы:** что показывает каждая страница, как листаются страницы и когда засыпает
экран — [`../../runtime-modules/display/README.md`](../../runtime-modules/display/README.md);
экран web UI — [`../../web-ui/settings-display.md`](../../web-ui/settings-display.md). BDD —
[`settings_display`](../../../../tests/dali2rust-bdd/features/settings_display/).

## Маршруты

| Метод | Путь | Ответ |
|---|---|---|
| `GET` | `/api/v1/settings/display` | `200` |
| `PATCH` | `/api/v1/settings/display` | `200` — применённые настройки |

`PATCH` — merge-patch с read-after-write; дисплей подхватывает изменение без
перезапуска. Настройки персистятся своим слайсом, который у каждой платы пары свой:
репликация конфигурации его не переносит, потому что панель стоит на своей плате.

## Поля

| Поле | По умолчанию | Смысл |
|---|---|---|
| `enabled` | `true` | Выключенный дисплей гаснет; события он копит, но экран не перерисовывает. |
| `i2c_address` | `60` (`0x3C`) | `60` или `61` (`0x3D`) — два адреса, которые выбирает перемычка SSD1306. |
| `rotation_deg` | `0` | `0` или `180`. |
| `screensaver_timeout_s` | `0` | `0` — хранитель выключен; иначе `10..86400` секунд без нового до того, как экран погаснет. |
| `pages` | `["summary"]` | Непустой список без повторов из `summary`, `network`, `bus`, `activity`; ответ возвращает их в этом порядке. |

- Поворот кратен половине оборота: панель 128×64 в четверть оборота дала бы экран
  64×128, на котором строка в 21 знак не помещается.
- Время показа страницы не настраивается.

## Ошибки

| Случай | Ответ |
|---|---|
| `rotation_deg` не `0` и не `180`, адрес не `60` и не `61`, таймаут хранителя вне диапазона, пустой список страниц или страница дважды, значение неверного типа | `422 invalid_value` |
| Неизвестная страница | `422 invalid_enum` |
| Неизвестное поле | `400 unknown_field` |
