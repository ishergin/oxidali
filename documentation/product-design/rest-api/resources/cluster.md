# Ресурс: Cluster

Параметры узла кластера: участвует ли контроллер в кластере, имя кластера, номер узла,
порт, провод DALI и что узел пересылает и принимает; статус узла и платы, которые он
слышит.

**Границы:** что делает кластер и почему —
[`../../runtime-modules/cluster/README.md`](../../runtime-modules/cluster/README.md) и
[ADR-035](../../../architecture/decisions/ADR-035-cluster-of-installations-over-udp.md);
узел и канал как термины —
[`../../glossary-and-invariants.md`](../../glossary-and-invariants.md). BDD —
[`cluster`](../../../../tests/dali2rust-bdd/features/cluster/).

## Маршруты

| Метод | Путь | Ответ |
|---|---|---|
| `GET` | `/api/v1/cluster` | `200` |
| `PATCH` | `/api/v1/cluster` | `200` — применённые настройки |
| `GET` | `/api/v1/cluster/status` | `200` — статус узла и слышимые платы |
| `DELETE` | `/api/v1/cluster/nodes/{node}` | `204` — замолкший узел забыт |

`PATCH` — merge-patch с read-after-write. Правила, связывающие два поля, проверяются на
сохранённых настройках вместе с патчем; отказанный патч не меняет ничего; пустой патч
ничего не пишет и отвечает `200` текущими настройками и на резервной плате. Настройки
персистятся своим слайсом `cluster_settings`; что из них забирает резервная плата —
[`config-transfer.md`](config-transfer.md) §Что переносится.

## Поля

| Поле | По умолчанию | Смысл |
|---|---|---|
| `enabled` | `false` | Участвует ли узел в кластере. |
| `cluster_name` | `""` | До 64 байт UTF-8; без имени кластер не включается. |
| `node_number` | `0` | `0..7`. |
| `port` | `47810` | UDP-порт кластера, `1..65535`. |
| `wire_same_as` | `null` | `null` — свой провод; номер узла `0..7` — тот же провод, что у этого узла. |
| `forward_operator` | `true` | Пересылать команды оператора. |
| `forward_home_assistant` | `true` | Пересылать команды Home Assistant. |
| `forward_hcl` | `false` | Пересылать уставки HCL. |
| `forward_foreign_master` | `false` | Пересылать кадры чужого мастера со сниффера. |
| `accept_all_lamps` | `false` | Исполнять входящие команды «всем». |
| `send_all_lamps` | `false` | Отправлять свои команды «всем» в кластер. |
| `accept_single_lamps` | `false` | Исполнять входящие команды одиночным лампам этого узла. |
| `wire_protection` | `true` | Защита от петли на общем проводе. |
| `read_only` | — | Только чтение: `true` на резервной плате. |
| `block` | — | `{first, last}` — блок номеров записей узла: `node_number·16 … node_number·16+15`. |

Источника «правила» нет: команды правил пересылаются только со стадией правил.

## Ошибки

| Случай | Ответ |
|---|---|
| Включение без имени или пустое имя у включённого кластера | `409 conflict`, `message: cluster_name_required` |
| `wire_same_as` называет этот же узел | `409 conflict`, `message: wire_names_this_node` |
| Защита выключена, чужой мастер пересылается и провод общий | `409 conflict`, `message: wire_protection_required` |
| Непустой патч на резервной плате | `409 controller_standby`, `Retry-After: 1`, `X-Dali2rust-Role: standby` |
| Номер, порт или провод вне диапазона, имя длиннее 64 байт, значение неверного типа | `422 invalid_value` |
| `read_only` или `block` в теле | `422 unsupported_field` |
| Неизвестное поле | `400 unknown_field` |
| `DELETE` узла, которого ещё слышно | `409 conflict`, `message: node_heard` |
| `DELETE` с номером узла вне `0..7` | `400 invalid_resource_id` |

## Статус

`GET /api/v1/cluster/status` — `{own, nodes, ignored}`, то же тело несёт кадр
`ClusterStatus` канала `cluster` ([`websocket.md`](websocket.md)).

`own` — этот узел:

| Поле | Смысл |
|---|---|
| `state` | `off` — кластер выключен; `no_address` — нет аренды адреса или MAC; `bind_failed` — порт не привязан, попытка повторяется раз в период пульса; `standby` — резервная плата: слушает, не передаёт; `listening` — первые два периода после привязки, номер ещё не занят; `waiting` — номер держит плата другой инсталляции; `running` — узел держит номер. |
| `node_number`, `wire` | Номер узла и номер провода, который узел называет в пульсе. |
| `board` | Имя платы `dali-xxxxxx` по MAC; `null` без MAC. |
| `boot_epoch` | Эпоха загрузки в заголовке каждого кадра этой платы. |
| `wire_owner` | Хозяин провода — живой узел с наименьшими номером и MAC среди называющих этот провод: `{node, board, this_node}`; `null` — никто. |
| `split_pair` | Две передающие платы одной инсталляции под одним номером. |
| `wire_chain` | Провод называет узел, который сам называет другой провод. |
| `number_held_by` | В `waiting` — плата, которая держит номер; иначе `null`. |

`nodes` — по одной строке на номер `0..7`, который кто-то держит или держал: `node`,
`board`, `address` (IPv4 источника), `installation`, `wire`, `wire_protection`,
`home_assistant_face` (`null`, пока плата не прислала hello), `heard` — живая ли плата,
`age_ms` — с последнего пульса, `sequence_gaps` — пропущенные номера кадров, `split` —
номер под разорванной парой. Строка живой платы показывается раньше замолкшей; замолкшая
держится, пока номер никто не занял, и уходит только по `DELETE`.

`ignored` — живые платы, которые узел слышит, но не считает узлами: `board`, `address`,
`node`, `reason`, `age_ms`. `reason`: `other_cluster` — другой кластер, его имя в
`cluster_name`; `waiting` — плата ждёт номер; `number_held` — номер держит другая плата.
Таблица держит до 24 плат; при переполнении вытесняется та, которую слышали давнее всех.

`DELETE /api/v1/cluster/nodes/{node}` забывает замолкшую плату под этим номером. Запрос
локальный: другие узлы забывают её сами. Счётчики датаграмм — блок `cluster` в
[`stats.md`](stats.md).
