# Экран: Groups

Матрица «виртуальная лампа × группа» адаптера (`#/groups`), имена групп и их лицо в Home
Assistant.

**Границы:** контракт — [`../rest-api/resources/groups.md`](../rest-api/resources/groups.md);
карточка — `web/design-system/screens/group-matrix.html`; общие правила матриц —
[`README.md`](README.md) §Матрицы групп и сцен.

## Матрица

Клик по ячейке привязанной строки копит правку; полоса Apply сохраняет строки и
программирует их на прибор. Заголовок столбца открывает поповер с именем группы и
переключателем Home Assistant.

## Группа в канале кластера

Группа, которая — часть канала кластера этого узла (`/api/v1/cluster/channel-parts`),
правится в канале: её столбец закрыт.

- Заголовок подписан номером канала вместо имени группы; клик открывает поповер со
  ссылкой на строку канала (`#/cluster/channels/{n}`) и переключателем Home Assistant,
  без поля имени.
- Ячейки показывают состав, но не переключаются.
- Под матрицей — какие группы в каких каналах и что их лампы с этого UI не меняются,
  пока нет редактора канала (стадия I6-D); чтобы править их здесь, группу сначала
  отвязывают в канале.
- Часть удалённого канала (сирота) закрывает столбец так же, со ссылкой на экран Cluster,
  где её снимает Finish delete.

Если части кластера не читаются, столбцы открыты: матрица от них не зависит. Подсчёт
строк, расходящихся с прибором, закрытые столбцы не исключает.
