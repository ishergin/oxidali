# Экран: Settings → Poller

Форма настроек фонового опроса (`#/settings/poller`).

**Границы:** контракт и смысл полей —
[`../rest-api/resources/settings-poller.md`](../rest-api/resources/settings-poller.md);
счётчики поллера — экран Diagnostics (блок `poller`); карточка —
`web/design-system/screens/settings-poller.html`.

- Форма читает `GET`, «Apply» шлёт один merge-patch с изменёнными ключами, после
  успеха форма перечитывает настройки.
- **Enabled** — с подписью, что по умолчанию опрос выключен и без него ничего не
  опрашивается.
- **Interval** — пресеты в один клик и числовое поле (зажим к `200 мс … 1 ч` при
  коммите), плюс строка «Wire share» `≤ 25 %` с подписью, что доля провода фона — не
  настройка и сама растягивает период (`interval_ms` в контракте).
- **Attribute groups** — чипы групп; пустой набор блокирует Apply (сервер тоже
  откажет). Банки 0 и 1 поллер не читает, банки Part 252/253 — только по переключателям
  ниже; подпись экрана «Memory banks are never polled» этому противоречит
  ([`../roadmap.md`](../roadmap.md) §Отложенные хвосты).
- **Add DT8 colour**, **Read energy banks**, **Read diagnostics banks**, **Skip unbound
  devices** — переключатели с подписью следствия (банки — только у приборов,
  объявивших соответствующий тип, и реже, чем опрос).
- Отказ сервера — тост, и черновик **остаётся**: сбросить его значило бы откатить форму
  к несохранённой серверной копии и потерять правки.
