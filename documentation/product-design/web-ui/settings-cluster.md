# Экран: Settings → Cluster

Параметры этого узла кластера одной страницей (`#/settings/cluster`) и строка узла в
сайдбаре.

**Границы:** контракт — [`../rest-api/resources/cluster.md`](../rest-api/resources/cluster.md)
(§Поля, §Статус, §Сведения узлов, §Ошибки); механизм —
[`../runtime-modules/cluster/README.md`](../runtime-modules/cluster/README.md); карточки —
`web/design-system/screens/settings-cluster.html`, `components/controller-role.html`.
Каналы и сцены кластера живут на Control → Cluster, а не здесь.

## Страница

Одна страница без вкладок и одна полоса Apply внизу: правки копятся в черновике, полоса
считает несохранённые поля и называет их, Discard возвращает сохранённое. Черновик
побеждает опрос: поле, которое контроллер догнал, из черновика выпадает.

- **This node** — `enabled`, имя кластера (обязательно для включения, до 64 байт),
  номер узла `0..7`, порт, строка состояния узла из `own.state` словами и имя платы. В
  списке номеров у номера, который держит услышанная плата, стоит её имя. Номер закрыт с
  причиной, пока узел — дом записей: число каналов и сцен берётся из строки `own`
  ресурса `/api/v1/cluster/info`; отказ `cluster_node_number_pinned` остаётся запасным
  путём.
- **Nodes heard** — строки `nodes` статуса: номер, плата, адрес, давность пульса (`ok` —
  слышен, `warn` — замолк), сводка того, что узел сам о себе сообщает (свой провод или
  чей, защита от петель выключена, пропуски кадров, разорванная пара, лицо Home
  Assistant), «Open» — веб-интерфейс узла по его адресу, и «Forget» у замолкшего узла.
  Сравнения настроек узлов статус не несёт, поэтому оценки «согласны» нет.
- **Heard, but not part of this cluster** — строки `ignored` с причиной словами; панели
  нет, пока список пуст.
- **Forward group commands given by** — оператор, Home Assistant, HCL, чужой мастер.
  Источника «правила» нет до стадии правил.
- **Share and accept** — отправка и приём команд «всем лампам». Приём команд одиночным
  лампам (`accept_single_lamps`) и рассылка событий входов не показаны до своих стадий.
- **DALI bus** — свой провод или тот же, что у узла k (свой номер в списке не
  предлагается, но сохранённое значение в нём остаётся), кто исполняет на общем проводе
  по `wire_owner`, цепочка проводов как `warn`, защита от петель. Числа пересылок API не
  отдаёт, и строки нет.

## Отказы

Отказ `PATCH` стоит у поля, которое он называет, словами, и полосой над панелями;
черновик остаётся:

| Причина | Поле |
|---|---|
| `cluster_name_required` | имя кластера |
| `wire_names_this_node` | провод DALI |
| `wire_protection_required` | защита от петель |
| `cluster_node_number_pinned` | номер узла |

`422 invalid_value` и `controller_standby` поля не называют и остаются в полосе. Номер,
порт и длина имени проверяются до отправки, поэтому `422` с экрана не приходит.

«Forget» — в два нажатия; `409 node_heard` тост называет словами: узел снова слышен, и
забыть можно только замолкший.

## Резервная плата

При `read_only` страница только для чтения: поля приглушены и не принимают ввод, полосы
Apply и «Forget» нет, а баннер говорит, что настройки приходят с активной платы раз в
30 с, и ведёт на неё по `peer_url` настроек отказоустойчивости.

## Живые данные

Статус приходит кадром `ClusterStatus` канала `cluster` WebSocket с телом REST-ресурса;
без сокета — опрос ([`websocket.md`](websocket.md)). Сайдбар и страница делят одно
хранилище статуса (`web/app/src/cluster-feed.ts`). Сведения страница опрашивает по REST:
кадр `ClusterInfo` о своих записях приходит, только пока узел держит номер.

## Строка узла в сайдбаре

Под названием, рядом со значком роли: имя платы и строка узла. Цвет — только у
неисправности, никогда не янтарный.

| Состояние | Строка | Цвет |
|---|---|---|
| кластер выключен | ничего | — |
| `running` | «Node n · h of k heard» по другим узлам статуса | `warn`, если кто-то замолк |
| `standby`, `listening` | «Node n · listening» | — |
| `waiting` | «Node n is taken by <плата>» | `err` |
| `split_pair` | «Pair split · see Redundancy», ссылка на Redundancy | `err` |
| `bind_failed` | «Node n · port not bound» | `err` |
| `no_address` | «Node n · no network address» | `warn` |

Сайдбар опрашивает статус раз в 15 с, пока сокета нет.
