# Экран: Log

Лог прошивки в браузере (`#/logs`) через канал WebSocket `logs` — диагностика там, где
симптом видит оператор, а USB-кабеля к контроллеру нет.

**Границы:** канал и его пределы — [`../rest-api/resources/websocket.md`](../rest-api/resources/websocket.md);
воркер WebSocket и кольцо лога —
[`../runtime-modules/websocket/README.md`](../runtime-modules/websocket/README.md);
карточка — `web/design-system/screens/logs.html`. BDD —
[`websocket`](../../../tests/dali2rust-bdd/features/websocket/).

## Экран

- По умолчанию выключен, как и сниффер: подписка открывается кнопкой, закрытый экран
  стоит контроллеру одной атомарной загрузки на строку.
- Выбор уровня (`error` / `warn` / `info` / `debug`) пересылает подписку с новым
  уровнем; фильтр по модулю и тексту — на клиенте.
- Браузер хранит последние 2000 строк, в DOM — не больше 400 новейших. Строки с уже
  виденным `seq` отбрасываются (вторая вкладка перематывает общий курсор, и строки
  приходят повторно); потеря показывается строкой-разрывом с числом потерянных.
- «Following» держит низ списка, «Held» фиксирует позицию; «Clear» чистит браузерный
  буфер.
- Время строки — часы контроллера; без привязанных часов экран так и подписывает.
