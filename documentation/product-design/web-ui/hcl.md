# Экран: HCL schedules

Список расписаний HCL (`#/hcl`) и редактор одного расписания (`#/hcl/{id}`).

**Границы:** контракт — [`../rest-api/resources/hcl.md`](../rest-api/resources/hcl.md);
часы — [`../rest-api/resources/controller.md`](../rest-api/resources/controller.md);
исполнение — [`../runtime-modules/hcl-scheduler/README.md`](../runtime-modules/hcl-scheduler/README.md);
карточки — `web/design-system/screens/hcl-schedules.html`, `hcl-editor.html`.

## Общее для страниц

- **Баннер «часы не синхронизированы»** (warn) — из `GET /api/v1/time` (`synced:
  false`): без привязанных часов не работает ни одно расписание. Состояние спрашивается
  у часов, а не у планировщика. Баннер ведёт на экран Settings → Time
  (`#/settings/time`), где время и пояс берутся из браузера или пояс вводится строкой
  POSIX TZ.
- **Полоса приостановки** под расписанием: «Standing down since HH:MM — {цели} were set
  by hand» и кнопка «Resume now» (`DELETE …/override`). Без неё приостановленное
  расписание выглядело бы так же, как работающее. Состояние приостановки — отдельный
  под-ресурс, поэтому список делает по одному дополнительному `GET` на расписание.

## Список

Карточка расписания: `schedule_id` (моно), переключатель `enabled` (мгновенный
`PATCH`), дни недели, сводка целей по адаптерам, алгоритм, ближайшая точка, статус.
Кнопка «New schedule» создаёт на сервере расписание-шаблон (`POST` без id) и, когда
запись легла, открывает его редактор — id берётся из тела `202`.

## Редактор

- **Точки** — таблица и мини-график суток (уровень — янтарная линия, температура —
  нейтральная). Астрономические точки на график не наносятся: браузер не считает
  положение солнца, и выдуманное время хуже честного «+N точек на восходе/закате».
  Линия уровня **обрывается** на точке `last_active`: уровень к неизвестному концу не
  интерполируется. Смена `level_mode` очищает поле, запрещённое в новом режиме.
- **Цели** — строки «адаптер + scope + группы»; дубли и превышение лимитов
  отсекаются на клиенте, сервер остаётся истиной.
- **Прочее** — алгоритм с однострочной подсказкой смысла, дни недели, координаты
  (обязательны при астрономических точках — форма это показывает), `enabled`.
- Полей плавности **нет**: подсказка отправляет к fade time прибора на карточке
  устройства.
- Сохранение — `PATCH` с массивами целиком; ответ `202` отслеживается как операция,
  и черновик сбрасывается только если запись легла (`opCommitted`). Ошибки `422`
  показываются у полей.
