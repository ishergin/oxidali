# Модуль adapter proxy (запланирован)

Проект модуля, который пробрасывает разрешённые групповые, сценовые и
широковещательные команды между локальными DALI-адаптерами одного контроллера. В коде
его нет: стадия `I7`, после многоадаптерной композиции `X2`
([`../../roadmap.md`](../../roadmap.md)).

Границы: зарезервированные значения контракта (`Origin::AdapterProxy`,
`RuntimeSource::AdapterProxy`, `adapter_proxy_origin_id` конверта) —
[`../../bus-contracts/commands.md`](../../bus-contracts/commands.md) §Конверт; объём
стадии — [`../../roadmap.md`](../../roadmap.md) §I7.

## Замысел

- **Вход**: наблюдения сниффера на адаптере-источнике и настройки прокси.
- **Выход**: семантические команды на адаптеры-цели с `origin = AdapterProxy`.
- **Состояние**: фильтры пересылки, метаданные происхождения, кэш подавления петель,
  счётчики.

## Ресурс

`GET` / `PATCH /api/v1/adapter-proxy` (merge-patch): включение, ограниченный список
правил «с адаптера → на адаптер» с группами и признаком broadcast, окно подавления
петель. Правило с одинаковыми адаптерами — `422`, несуществующий адаптер — `404`.

## Правила

- Разрешённая групповая команда адаптера A пересылается на адаптер B; recall сцены —
  как `DaliRecallSceneCommand` с исходным scope; broadcast — только по явной настройке.
- Запрещённая команда отбрасывается со счётчиком.
- Привязка лампы к устройству другого адаптера запрещена.
- Пересланная `DaliSetTargetStateCommand` подчиняется очереди и коалесингу адаптера-цели
  так же, как команда любого другого источника; переполнение — отказ со счётчиком.
- Петли гасятся метаданными происхождения и кэшем подавления.
- Что прокси значит для языка правил — [`../rules-engine/operations.md`](../rules-engine/operations.md)
  §5.
