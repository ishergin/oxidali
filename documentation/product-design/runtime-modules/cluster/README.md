# Модуль cluster (запланирован)

Проект модуля, который синхронизирует разрешённые групповые команды и recall сцен между
контроллерами через MQTT. В коде его нет: стадия `I6` ([`../../roadmap.md`](../../roadmap.md)).

Границы: зарезервированные под него значения контракта (`Origin::Cluster`,
`RuntimeSource::Cluster`, `cluster_origin_id` конверта) —
[`../../bus-contracts/commands.md`](../../bus-contracts/commands.md) §Конверт; объём
стадии — [`../../roadmap.md`](../../roadmap.md) §I6.

## Замысел

- **Вход**: принятые локальные семантические команды разрешённых scope (`Group`,
  `Broadcast`, recall сцены) — основной источник пересылки; наблюдения сниффера — только
  как свидетельство для подавления петель и диагностики; MQTT-сообщения других узлов.
- **Выход**: MQTT-сообщения узлам и локальные семантические команды с
  `origin = Cluster` для принятых удалённых команд.
- **Читает**: настройки кластера, фильтр пересылки и адаптер, на который ложится
  входящее.
- **Состояние**: соединение, идентификатор происхождения, кэш подавления петель,
  счётчики.

## Ресурс

`GET` / `PATCH /api/v1/cluster` (merge-patch): включение, транспорт (MQTT с префиксом
топиков), политика — какие группы и broadcast пересылать наружу и принимать извне, —
окно подавления петель. `controller_id` только читается: он берётся из настроек Home
Assistant и служит происхождением сообщений кластера. Группа вне `0..15` — `422`.

## Правила

- Пересылаются только разрешённые фильтром групповые и широковещательные цели;
  команды по короткому адресу наружу не уходят никогда.
- Удалённая групповая команда становится локальной `DaliSetTargetStateCommand`,
  удалённый recall — локальной `DaliRecallSceneCommand` с исходным scope.
- Петли гасятся метаданными происхождения и кэшем подавления; пересланное не
  возвращается к отправителю.
- Потеря соединения — автоматическое переподключение **без** проигрывания удалённых
  команд; согласованность узлов — eventual, через проекцию, поллер и сниффер.
- Исходящий путь ограничен; при насыщении — отказ со счётчиком. Модуль не блокирует
  `DaliWorker` и не держит блокировок реестра на сетевых операциях.
- Полной синхронизации реестров модуль не делает.

Что решить до начала работы — [`../../roadmap.md`](../../roadmap.md) §I6.
