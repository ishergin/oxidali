# Модуль stats

Продуктовая статистика `GET /api/v1/stats`: компактный снимок поверх счётчиков,
которые рантаймы ведут в памяти. Отдельного потока нет, на шину ничего не публикуется.

Границы: блоки, DTO и правила чтения — [`../../rest-api/resources/stats.md`](../../rest-api/resources/stats.md);
сырые счётчики по путям — [`../../rest-api/resources/diagnostics.md`](../../rest-api/resources/diagnostics.md);
как счётчик доходит до поверхности и куда идёт новый —
[`../../../architecture/04-contracts-and-api-bridge.md`](../../../architecture/04-contracts-and-api-bridge.md)
§Counter surface. Код — хендлер и DTO в `dali2rust-api` (`stats_state`), мост к
счётчикам — композиция `dali2rust-adapters`.

## Правила

- **Read-модель, не событие.** Полный снимок не помещается в 128-байтный кадр, поэтому
  шина его не несёт, и объявленный `StatsReportedEvent` издателя не имеет.
  WebSocket-канал `stats` — тот же снимок по таймеру.
- **Инкремент без блокировок** (`AtomicU32`), снимок — relaxed-чтение.
- Статистика волатильна: не персистится, историей не хранится и реестр не мутирует.

## Тесты

Чёрный ящик: DTO соответствует контракту, `GET` ничего не публикует, блоки отражают
реальные счётчики (`tests/dali2rust-bdd/features/stats/`). Отдельные счётчики
доказываются крейт-тестами своих рантаймов.
